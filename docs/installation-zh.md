将 **engineering-microinnovation-v0.1.0.zip** 上传给工作伙伴里的 evolution，要求按所在工具支持的方式安装为 Skill。包内包含完整脚本和案例资料；不要只复制说明文字。

## 安装后生成首例

> 用 Skill 内置的 CASE-001 示例参数，不修改参数与文字，运行一次 generate，再运行 verify。请将全部输出文件打包下载，同时单独提供 viewer.html、render.png、components.xlsx 和校核报告。无需联网、无需 CAD 或 SketchUp；效果图必须由脚本生成的模型渲染。

随后打开下载后的 `02_model/viewer.html`。检查模型显示、拖动旋转、滚轮缩放、网格开关、剖切及截图导出；可以断网检查。HTML 在平台预览中被禁用脚本，不代表下载后的浏览器也无法运行，应分别记录。

## 四项试装验收

| 项目 | 本次需要你验证的结果 |
|---|---|
| 带脚本的 Skill 能否安装 | 安装结果、脚本/资源是否完整 |
| Python 能否运行 | probe.json、生成日志或报错 |

| 同需求连跑三次是否一致 | 独立整理的参数 JSON、每轮 manifest 和差异报告 |

详细三次试验提示词见包内 `references/platform-trial.md`。先做“固定参数三次”，再做“三个独立会话中的相同自然语言需求”。两者不能混同：AI 文本与参数可能漂移，即使脚本完全确定。

试完把成功结果或报错、probe.json 和每轮 manifest 发回本任务即可继续定位。不要发送账号口令或其他凭据。

## 当前工程与产品边界

首版只支持既有案例的 9 项尺寸，整体布局固定。图纸为包含遮挡边的线框设计草案；传振节点、结构验算、材质、焊缝、螺纹、公差待工程师复核。标准规则目前只检查条款证据字段完整性，没有自动判断规范符合性。

方案、工法、专利交底和 QC 提供可扩展模板及 Word/Markdown 草案，缺少证据的部分保留待补充，不能直接作为正式申报文件。加工制作、正式申报、受力关键构件须由工程师用适用专业软件复核。
