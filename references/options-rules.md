# 方案比选规则

先明确安装边界、荷载传递路径和可复核依据，再比较方案。通常保留既有方案、拟议改进方案和可实施替代方案；若不足三种，不为凑数虚构。

对每个方案记录：解决的问题、关键构件与连接、操作步骤、可加工性、拆装影响、质量控制、成本信息来源、主要风险、缺失证据。

硬约束优先：无法安装、传力路径不成立或关键条件未知时，标记淘汰/待验证，不能用主观评分抵消。软指标可按用户确认的权重比较；未给权重时用并列优缺点，不编造总分。

选定理由只引用输入证据。无试验/工程复核时用“待验证方案”。数量、长度、重量和材料用量不由语言模型估计后写入清单；首版只提供模型实例数量，尚不提供采购/下料/重量统计。
